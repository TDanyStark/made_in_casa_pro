# Project costs: associated charges per project and version
A new "Costos" section in the project lets the commercial and directivos record charges that are not task costs (commercial payment, commercial tasks, tools/credits).
Those charges count in the project's investment and margin, and can be filtered by version like task costs.

## Specs
S1. "Quiero que dentro de los proyectos crees otra seccion que se llame costos" — a "Costos" tab in the project detail.
S2. "esto para que el comercial o los directicos (directivo, admin, financiero) puedan agregar costos de ese proyecto" — admin, directivo and financiero on every project; the commercial only on projects they created (same rule as the sale price). Edit/delete: "Cualquiera de esos roles". Colaboradores never see the tab nor the costs.
S3. "por ejemplo el pago al comercial, o las tareas de los comerciales, viste que ellos pueden tener tareas asignadas pero no aparecen dentro de los cobros, por ejemplo si se compra una herramietna como tockens de chatGPT, o creditos de higgsfield etc, cobros asociados" — commercial tasks enter as a manual cost ("Costo manual en 'Costos'"), optionally linked to a task of the project; salaries are not touched.
S4. "esto para que luego en las metricas tambien en la rentabilidad se tomen en cuenta estos cobros asociados, del proyecto para ver la rentabilidad real" — associated costs add to the total cost and reduce the margin in the financial cards and the Métricas tab, shown as their own line/breakdown.
S5. "actualmente los costos están asociados a las tareas, ¿vale? En la versión 1 puede haber unas tareas y, en la versión 2, otras. Aunque el proyecto macro es uno solo y la rentabilidad es una sola, luego yo puedo filtrar, por ejemplo, cuánto gastamos en la V1 y cuánto gastamos en la V2.Entonces, algo igual para los cobros, ¿vale? Debe pedir la versión: ¿a qué versión está asociado ese cobro, a la versión 1 o a la versión 2? Obviamente, si hay más versiones. Si solo hay una versión, no debe preguntar qué versión." — every cost belongs to a version; the form asks for it only when the project has 2+ versions (otherwise it takes the only one); the existing version filter also filters associated costs; margin stays for the whole project.
S6. "Creo que una lista fija más descripción estaría bien, pero debe ser fácil crear esas categorías, ¿sabes? Como un search en un select que, si no está la opción, se pueda crear fácilmente." — each cost has a category (searchable select that creates a missing category inline) plus a free description.
